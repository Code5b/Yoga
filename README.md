## 1. 项目概述

### 1.1 项目背景

当前瑜伽馆的日常运营存在以下痛点：

- **约课混乱**：依赖微信接龙、私聊报名，信息分散易遗漏，学员经常搞错时间
- **会员管理低效**：会员卡项、剩余次数依赖Excel手工登记，经常出现“记得不对”的纠纷
- **财务不透明**：合伙经营但账目手工记录，对账困难，缺乏信任基础
- **缺少增长工具**：没有系统化的拉新和留存手段，完全依赖口碑自然增长
- **教练管理空白**：教练课表、学员信息、课时统计全部人工处理

### 1.2 项目目标

通过开发一款微信小程序 + 配套管理后台，实现：

1. **约课线上化**：会员自助预约、取消、候补，减少人工沟通成本80%
2. **管理数据化**：会员、课程、财务全部线上可查，合伙人对账一目了然
3. **营销自动化**：内置拼团、秒杀、老带新等工具，持续带来新客
4. **教练数字化**：教练可查看课表和学员信息，上课确认形成闭环
5. **决策智能化**：通过数据分析指导排课优化、会员运营和推广投入

### 1.3 使用角色定义

| 角色 | 人数预估 | 使用端 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **会员** | 100-500人 | 微信小程序 | 约课、查看课表、管理卡项、参与活动 |
| **前台/店长** | 1-3人 | PC管理后台 + 小程序核销端 | 排课、核销、会员服务、日常运营 |
| **教练** | 2-6人 | 微信小程序（教练模式） | 查看课表、确认上课、查看学员信息 |
| **合伙人** | 2-3人 | PC管理后台（全部权限） | 财务管理、数据分析、重大决策 |

### 2.1 启动页与登录

#### 2.1.1 启动页
- **展示内容**：品牌Logo + Slogan（如“在呼吸间遇见自己”）
- **显示时长**：2秒后自动进入登录页，或点击“跳过”直接进入
- **背景**：淡雅渐变或静态瑜伽意境图

#### 2.1.2 登录页
- **布局**：
  - 顶部：品牌Logo + 名称
  - 中部：Slogan（如“随时随地，约课练习”）
  - 底部：【微信手机号一键登录】按钮（绿色按钮，符合微信规范）
- **交互逻辑**：
  - 点击按钮 → 调起微信授权弹窗 → 用户确认授权 → 获取手机号
  - 首次登录时，自动创建会员档案，弹出《用户协议》和《隐私政策》勾选框
  - 未勾选协议无法登录（弹窗提示“请先阅读并同意协议”）
- **异常处理**：若微信授权失败，显示“授权失败，请重试”按钮

#### 2.1.3 协议页面
- 独立页面，通过登录页的“《用户协议》”和“《隐私政策》”文字链接跳转
- 内容由后台系统设置中的“隐私政策/用户协议”编辑框控制

### 2.2 首页

> **页面路径**：`pages/home/index`  
> **页面角色**：用户进入小程序的第一屏，核心流量分发入口

#### 布局（自上而下）：

##### 2.2.1 顶部状态栏
- 左侧：定位/场馆名称（如“北京·朝阳馆”），可点击切换分馆（如有）
- 右侧：【消息小铃铛】图标，带未读红点数量
- 点击铃铛 → 进入消息列表页（系统通知、活动推送等）

##### 2.2.2 搜索栏
- 占位符文案：“搜索课程、教练...”
- 点击进入搜索页 → 输入关键词搜索课程名称或教练姓名 → 展示匹配结果列表

##### 2.2.3 轮播图（Banner）
- **尺寸比例**：16:9（宽度自适应）
- **展示数量**：3-5张，自动轮播（间隔3秒），支持手动滑动
- **可配置内容**：活动宣传、新课程推广、品牌故事、节假日祝福等
- **交互**：点击Banner → 跳转至配置的目标页面（课程详情页/活动落地页/拼团页面/H5外链）
- **数据来源**：后台“内容管理 > 首页轮播图”配置

##### 2.2.4 金刚区（核心功能入口）

> 2行 × 4列，固定显示前4个，其余收起在“更多”中

| 位置 | 图标名称 | 图标建议 | 跳转目标 |

| 1 | 约团课 | 🧘 瑜伽小人 | 约课页面（默认筛选“团课”） |
| 2 | 约私教 | 💬 对话气泡 | 约课页面（默认筛选“私教”） |
| 3 | 我的课程 | 📅 日历 | 我的课程列表（待上课Tab） |
| 4 | 我的卡包 | 💳 卡券 | 我的卡包页面 |
| 5 | 积分商城 | 🎁 礼物盒 | 积分商城页面 |
| 6 | 签到打卡 | ✅ 对勾 | 签到打卡页面 |
| 7 | 推荐有礼 | 📤 分享 | 我的推荐页面 |
| 8 | 全部课程 | 📋 列表 | 约课页面（全部Tab） |

- **交互**：点击任一入口 → 跳转至对应页面
- **配置**：后台可调整图标顺序、显示/隐藏、跳转链接

##### 2.2.5 运营活动模块（动态展示）

| 活动类型 | 展示样式 | 说明 |
| :--- | :--- | :--- |
| **限时秒杀** | 卡片+倒计时（时:分:秒） | 展示当前进行中的秒杀活动，点击进入活动页 |
| **热门拼团** | 卡片+参与人数进度条 | 展示当前拼团活动，点击进入活动页 |
| **体验课推荐** | 卡片+“¥9.9起”标签 | 引导新用户购买体验课 |

- **展示逻辑**：优先显示进行中的活动；若无活动，隐藏该区域
- **数据来源**：后台“营销工具 > 拼团/秒杀管理”

##### 2.2.6 今日推荐课表

- **展示内容**：当天前3节课程（按时间从早到晚排序）
- **课程卡片信息**：
  - 课程封面小图（教练形象或课程图标）
  - 课程名称（如“哈他瑜伽 · 基础”）
  - 时间段（如“19:00-20:00”）
  - 教练姓名
  - 剩余名额（如“余5席/共12席”，名额≤3时显示红色“紧张”标签）
- **交互**：点击卡片 → 进入课程详情页
- **底部按钮**：【查看全部课表】→ 跳转至约课页面

##### 2.2.7 场馆介绍快捷入口（悬浮或底部）
- 轻量展示：场馆环境照片1-2张 + “了解我们”
- 点击进入场馆介绍页面（图文展示场地、设施、品牌故事）

### 2.3 约课页面

> **页面路径**：`pages/booking/index`  
> **页面角色**：课程浏览与预约的核心页面

#### 2.3.1 顶部筛选Tab
- 固定Tab栏：全部 | 团课 | 私教 | 特色课（如空中瑜伽、高温瑜伽、普拉提）
- Tab数量可后台配置（最多5个）
- 切换Tab → 下方课表刷新为对应类型的课程

#### 2.3.2 日期选择栏
- 水平滑动选择日期（默认选中“今天”）
- 显示格式：`今天 8/18`、`周五 8/19`、`周六 8/20`...
- 可滑动范围：今天 + 未来7天（共8天）
- 交互：点击某一天 → 下方课表刷新为对应日期的课程

#### 2.3.3 课程列表（按时间排序）

**每个课程卡片包含**：

| 信息项 | 说明 |
| :--- | :--- |
| 时间区块 | 左侧独立显示“19:00-20:00” |
| 课程封面 | 小尺寸方形图（教练或课程象征图） |
| 课程名称 | 加粗显示，如“哈他瑜伽” |
| 教练姓名 | 如“Lily老师” |
| 教室/地点 | 如“1号教室” |
| 剩余名额 | 如“余5席/共12席”，名额紧张时文字变红色 |
| 操作按钮 | 状态自适应：有空位显示【预约】；满员显示【候补】；已预约显示【已约】（不可点击） |

- 课程按开始时间从早到晚排序
- 已结束的课程置灰显示，不可点击

#### 2.3.4 空状态
- 当日无课程时显示：“今日暂无课程，去看看其他日期吧”
- 配以空状态插图（瑜伽垫图标）

#### 2.3.5 下拉刷新与加载
- 下拉触发刷新（重新加载课表数据）
- 上拉加载更多（仅当天课程较多时触发）

### 2.4 课程详情页

> **页面路径**：`pages/course/detail`  
> **页面角色**：展示课程详细信息，完成预约操作

#### 2.4.1 页面布局

##### 头部轮播图（3-5张）
- 展示：教练形象照、课程练习场景、场馆环境
- 支持手动滑动

##### 课程基本信息区域
- 课程名称（大号加粗）
- 星级评分（如 ★★★★☆ 4.8分）+ 评价条数（如“128人评价”）
- 已预约人数 / 总容量（如“已约8人/共12人”）
- 价格信息：若为私教课显示“¥XXX/节”，若为团课显示“次卡可用”

##### 教练简介区域
- 头像（圆形）+ 姓名 + 职称（如“高级瑜伽导师”）
- 擅长领域标签（如“哈他瑜伽”“流瑜伽”“肩颈理疗”）
- 教练介绍文字（可展开/收起，超过3行显示“...展开”）
- 点击教练头像 → 进入教练个人主页（可查看教练所有课程）

##### 课程介绍区域
- 富文本展示（支持图文混排）
- 内容包含：适合人群、课程益处、练习注意事项
- 若为特色课，展示特色说明（如“空中瑜伽需自备长裤”）

##### 未来7天开课时间列表
- 以列表形式展示未来7天该课程的所有开课时间
- 每个条目包含：日期、时间段、剩余名额、状态
- 状态按钮：有空位【预约】/ 满员【候补】/ 已约【已约】
- 点击【预约】→ 弹出确认框 → 确认后预约成功 → 返回结果页

##### 评价区（精选展示）
- 展示最近3条5星好评（含用户头像、昵称、评价内容、时间）
- 底部按钮【查看全部评价】→ 跳转至课程评价列表页

##### 底部固定操作栏
- 左侧：收藏按钮（❤️ 收藏课程，收藏后可在“我的>我的收藏”查看）
- 右侧：主操作按钮（预约/候补/已约，状态与卡片一致）

#### 2.4.2 预约确认弹窗
- 内容：课程名称、日期、时间、教练
- 确认按钮：【确认预约】
- 取消按钮：【取消】
- 预约成功后 → 自动跳转至“我的课程”页面（待上课Tab）
- 推送通知：发送“预约成功”模板消息

#### 2.4.3 候补确认弹窗
- 内容：提示“当前课程已满，加入候补队列？”
- 确认按钮：【加入候补】
- 候补成功后 → 显示候补排名（如“当前候补第3位”）
- 推送通知：当有空位时，按候补顺序自动预约并推送通知

### 2.5 我的课程

> **页面角色**：查看所有预约记录，管理待上课和已完成课程

#### 2.5.1 顶部Tab切换
- 待上课 | 已完成 | 已取消/爽约
- 每个Tab右上角显示数量角标（如“待上课 3”）

#### 2.5.2 待上课列表

  - 课程名称 + 教练姓名

#### 2.5.4 已取消/爽约列表
- 显示：课程名、原定时间、取消原因（用户取消/系统取消/爽约）
- 爽约标记：红色“爽约”标签 + “已扣减1次课程次数”提示

#### 2.5.5 空状态
- 待上课为空时：“暂无待上课，去约课吧”→ 按钮【去约课】
- 已完成为空时：“还没有上课记录”
- 已取消为空时：“暂无取消记录”

### 2.7 个人中心（我的）

> **页面路径**：`pages/my/index`  
> **页面角色**：用户信息管理、功能入口聚合

#### 2.7.1 头部用户信息区
- 圆形头像（微信头像）
- 昵称（微信昵称）
- 会员等级（如“白银伽人”“黄金伽人”“钻石伽人”，根据累计上课次数自动升级）
- 累计上课天数（显示“已练习 68 天”）

#### 2.7.2 核心数据卡片（横向排列）
| 数据项 | 说明 |
| :--- | :--- |
| 累计上课 | 总到课次数 |
| 积分余额 | 当前积分 |
| 卡项数量 | 持有有效卡项数量 |

## 5. 核心业务流程与规则

### 5.1 预约与核销闭环

用户预约 → 生成“待上课”记录 → 到店出示核销码 → 前台扫码 →
系统校验：该用户是否有该课程的预约记录 → 有则继续 →
系统校验：卡项是否有效（次数卡有剩余次数/期限卡在有效期内） →
校验通过 → 扣减卡项次数（或仅记录签到）→ 状态变更为“已完成”→
记录签到时间 → 推送“上课完成”通知（可选）

### 5.2 爽约与惩罚机制

- **定义**：开课前2小时内取消预约 = 爽约
- **记录**：系统自动记录爽约次数（30天滚动计算）
- **触发**：30天内累计爽约满3次 → 系统自动暂停小程序预约权限7天
- **通知**：达到第2次爽约时，推送提醒“再爽约1次将暂停预约权限”
- **恢复**：7天后自动恢复，爽约计数归零
- **后台配置**：取消时限、爽约阈值、暂停天数均可由合伙人在“系统设置-预约规则配置”中调整

### 5.3 候补机制

- **触发**：课程已满员时，用户可点击【加入候补】
- **排队**：按加入候补的时间先后排序（先到先得）
- **自动预约**：当有名额空出（用户取消或爽约）时，系统按候补顺序自动为候补用户预约
- **通知**：候补成功后，立即推送“候补成功”订阅消息
- **失效**：课程开始前2小时，若仍未候补成功，候补记录自动失效（推送“候补失败”通知）
- **限制**：同一用户同一课程只能候补1次

### 5.4 体验课转化流程

后台生成体验课兑换码（可设置批次名称、有效期、适用课程）
↓
通过推广渠道发放兑换码（线下扫码/线上投放）
↓
用户在小程序“我的卡包”输入兑换码 → 系统验证有效性（未使用、在有效期内）
↓
验证通过 → 兑换码绑定至该会员账户 → 生成一张“体验课”卡项
↓
用户使用体验课卡项预约指定课程
↓
到店核销上课 → 前台系统标记该用户为“已体验”
↓
系统自动通知销售/前台跟进转化办卡

### 5.5 停课/放假管理

**整馆停课流程**：
1. 后台“排课管理 > 假期/停课设置”中设置停课日期段（如2026-10-01至2026-10-07）
2. 系统自动查询该时间段内所有已预约记录
3. 自动取消所有预约 → 推送“课程取消通知”给所有受影响学员
4. 小程序端该日期段所有课程隐藏，显示“场馆休息中”

**单节课停课/调整流程**：
1. 后台“排课管理 > 临时调课”中选择课程 → 选择操作类型（停课/更换教练/调整时间）
2. 操作确认后，系统自动推送变更通知给所有已预约学员
3. 小程序端实时更新课程信息

### 5.6 拼团业务规则

1. **发起拼团**：用户选择拼团商品 → 支付拼团价 → 成为团长 → 生成拼团链接
2. **参团**：其他用户点击团长分享的链接 → 支付拼团价 → 加入该团
3. **成团条件**：规定时间内（如24小时）达到设定人数（2人或3人）
4. **成团成功**：所有成员自动获得对应卡项 → 推送“拼团成功”通知
5. **拼团失败**：超时未成团 → 系统自动原路退款（微信支付） → 推送“拼团失败退款通知”
6. **限制**：同一用户同一拼团活动只能参与1次

### 5.7 秒杀业务规则

1. **创建**：后台设置秒杀商品、秒杀价格、库存数量、活动时间
2. **展示**：小程序首页显示秒杀活动入口+倒计时
3. **抢购**：活动开始后，用户点击购买 → 扣减库存 → 生成订单 → 调起支付
4. **超卖防护**：使用Redis原子操作扣减库存，防止超卖
5. **未支付处理**：订单生成后15分钟内未支付 → 订单自动取消 → 库存回补
6. **限购**：同一用户同一秒杀活动限购1次

## 10. 隐私与合规

### 10.1 隐私政策要求
- 首次登录必须勾选同意《用户协议》和《隐私政策》
- 隐私政策需明确告知：收集的个人信息范围（手机号、微信昵称、头像）、使用目的（约课、会员管理）、存储方式、数据安全措施
- 后台“系统设置”中支持随时编辑隐私政策内容，小程序端实时更新

### 10.2 数据权限隔离

| 角色      | 可见数据范围                                                 |
| :-------- | :----------------------------------------------------------- |
| 教练      | 仅可见自己名下课程的学员名单（手机号脱敏），不可查看其他教练课程 |
| 前台/店长 | 可见所有会员基本信息，不可导出手机号列表                     |
| 合伙人    | 全部数据可见，具备导出权限                                   |

### 10.3 数据删除权
- 用户可在“个人中心 > 设置 > 注销账号”申请注销
- 注销流程：用户提交申请 → 确认弹窗（“确认注销后将删除所有个人信息”）→ 输入验证码确认 → 提交后台
- 后台收到注销申请后，15个工作日内处理完成
- 注销完成后，该会员的所有个人信息从生产数据库中删除或匿名化

### 10.4 数据加密要求
- 会员手机号在数据库中加密存储（AES-256或同等级别）
- 数据传输全链路使用HTTPS
- 后台登录密码使用bcrypt加密存储

### 10.5 操作审计
- 所有后台操作（登录、查看敏感数据、修改数据、导出报表）均记录操作日志
- 操作日志包含：操作人、操作时间、IP地址、操作类型、操作内容
- 操作日志保存至少180天，仅合伙人有权限查看

## 14. 附录三：开发优先级与分阶段计划

### 14.1 第一阶段（P0）— MVP核心闭环

**周期**：1-2个月  
**目标**：替代手工登记，跑通“线上预约-线下核销”最小闭环

| 模块     | 功能列表                                                     |
| :------- | :----------------------------------------------------------- |
| 小程序端 | 首页、约课页面（课表浏览+预约）、我的课程（待上课列表）、我的卡包、手机号登录、课程详情页、简单个人中心 |
| 管理后台 | 排课日历（周视图）、新建课程（单次+循环）、课程列表管理、扫码核销、手动签到、会员列表、今日签到记录、经营看板（基础版） |
| 基础设施 | 预约成功/上课提醒/取消通知（订阅消息）、隐私协议、用户协议   |

### 14.2 第二阶段（P1）— 增长与转化

**周期**：1-2个月  
**目标**：提升会员粘性及拉新能力

| 模块     | 功能列表                                                     |
| :------- | :----------------------------------------------------------- |
| 小程序端 | 老带新推荐海报、课程评价、积分商城（基础版）、签到打卡、拼团页面、秒杀页面、搜索功能、购卡商城 |
| 管理后台 | 教练端（课表+学员名单+确认上课）、优惠券管理、兑换码管理、拼团/秒杀管理、裂变老带新管理、渠道追踪（基础版）、课程评价管理、内容管理（轮播图） |
| 基础设施 | 候补排队通知、卡项到期提醒、爽约惩罚机制                     |

### 14.3 第三阶段（P2）— 精细化运营

**周期**：按需迭代  
**目标**：数据驱动决策与自动化营销

| 模块     | 功能列表                                                     |
| :------- | :----------------------------------------------------------- |
| 小程序端 | 打卡挑战（21天）、短视频/直播模块、好友砍价、幸运转盘、会员动态流（打卡秀） |
| 管理后台 | 会员活跃度四象限分析、自动化召回券发放、教练业绩报表、财务报表（增强版）、会员标签营销、群发消息、操作日志、数据导入导出、多门店支持（如需） |
| 基础设施 | 会员等级自动升级、生日自动祝福推送、经营日报自动推送         |
