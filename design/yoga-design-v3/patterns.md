# Yoga 业务 Pattern V3

业务交互模式索引。所有 Pattern 严格对应 PRD 状态机，UI 组件在 `components.html`，落地示例在 `user-showcase.html` / `admin-showcase.html`。

## 1. 任务闭环（管理端核心）「今天应该做什么」

```text
业务事件 → 系统判断 → 运营任务 → 员工处理 → 结果 → 下一步任务
```

- **事件**：体验课完成、会员 7 天到期、14 天未训练、私教余额 20%、商品低库存、今日预约未签到。
- **任务等级**：P0 红（立即）、P1 黄（今日）、P2 蓝（本周）、P3 灰（观察）。
- **处理必须选结果**：已成交 / 有意向 / 考虑中 / 无意向 / 联系不上 / 转交，结果决定下一步任务。
- 任务卡：左侧 3px 优先级色条 + 标题 + 元信息 + 操作区，见 `.y-task.p0-p3`。

## 2. 课程状态机（用户端约课）

```text
可预约 → 已预约 → 已完成（签到核销）
            └→ 已满 / 候补
可预约 →（资格校验）→ 无权益 / 时间冲突
已结束 → 未签到按规则处理
```

- 课程卡 7 态：可预约 / 已预约 / 已满 / 候补 / 无权益 / 时间冲突 / 已结束。
- 资格校验顺序：会员权益 → 时间冲突 → 库存容量，任一不满足即提示对应状态。
- 预约确认 Sheet 必须展示「扣减权益 + 取消规则」，成功后再展示预约号。

## 3. 会员状态机（4 态）

```text
正常 → 次数不足（预警）→ 7 天到期（P0 触达）→ 已到期（召回）
```

- 会员卡 4 态：正常 / 次数不足 / 7天到期 / 已到期。
- 管理端会员中心按状态分组（全部 / 新用户 / 体验未成交 / 活跃 / 高价值 / 沉默 / 到期）。

## 4. 签到消课（管理端）

- 扫码/手动签到 → 系统校验预约与权益 → 确认核销 → 累计积分。
- 离线保障：签到 / 退款 / 库存 / 价格必须联网确认后才显示成功（见管理端「更多」页）。

## 5. 续费与召回触达

- 7 天内到期 → 按历史价值排序，P0 触达高价值会员。
- 14 天未训练 → 沉默召回名单，推荐线上训练 / 短期卡。
- 私教剩 20% → 先完成阶段复盘，再触发续购建议。

## 6. 沉浸式训练（用户端训练页）

- 深色沉浸容器 `y-immersive`：进度环 + 打卡周历 + 今日课程 + 直播入口。
- 训练中状态强调「当前进度」，用 `y-ring` + `y-progress-dark`，主按钮为唯一品牌色元素。

## 7. 商品关联推荐

- 训练计划 ↔ 装备套餐 ↔ 数字课程互相推荐，文案带训练理由（「你正在做柔韧训练…」）。

## 8. 购买 / 售后

- 购买 → 订单可追溯 → 使用流水可查 → 退款规则门店公示。
- 权益与商品订单统一归口「我的 → 消费记录」。

## 视觉约束

- 禁止 Emoji；图标统一从 `icons/sprite.svg` 引用。
- 圆角 4/6/8/12，沉浸容器与抽屉才用 12。
- 品牌黄只用于强调：主按钮 / 关键标签 / 进度；页面底色暖灰 `#F6F5F2`。
- 数字统一 `tabular-nums`，大数字用 `.y-num` / `.y-kpi-value`。
