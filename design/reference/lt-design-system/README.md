# LT Design System — Source Reference

这是本仓库 Yoga 商用设计系统的源参考，来自用户提供的 LT Design System。

LT Design System 的核心视觉语言：
- 金色明黄主色 `#FFD600`
- 温暖、活力、移动端友好
- 三层 Token：Brand Tokens → Portable Aliases → Typography Classes
- 中文移动应用优先
- 圆角：6 / 10 / 16px
- 间距：4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24px
- 字体优先使用 PingFang SC / Apple 系统字体
- 状态色：成功 `#07C160`、警告 `#FF9500`、错误 `#FF4444`、信息 `#3B82F6`
- 组件强调实心金色按钮、描边按钮、文本按钮、FAB、徽章、头像、搜索、底部 TabBar、卡片

本目录用于保存源设计系统，不直接修改其品牌语义。Yoga Design System 在 `design/yoga-ds/` 中以同一 Token 体系扩展瑜伽业务语义。
