# Yoga Design System V2

> 商用级重构版本。严格继承 LT Design System 的视觉基因，并针对 Yoga 单店经营、会员增长、交易履约、课程预约、CRM、商品与运营任务进行业务扩展。

## 重构原则

1. **适度圆角**：业务卡片 10px，控件 8px，小标签 6px；仅胶囊/状态筛选使用 999px。
2. **高密度但不拥挤**：页面横向安全边距 16px，卡片内间距 12px，核心信息间距 8px；减少无意义留白。
3. **中文优先**：以 PingFang SC / Noto Sans SC / system-ui 为字体栈，减少英文装饰文本。
4. **专业高级**：LT 的 #FFD600 仅作为品牌强调色，不大面积铺色；主体采用中性灰阶、明确层级、细边框和轻阴影。
5. **沉浸式交互**：课程摄影、教练照片、训练进度、底部抽屉、滚动状态、预约确认和结果反馈共同形成业务体验。
6. **无 Emoji**：所有图标统一来自 `icons/` SVG 资源库，禁止使用 emoji 作为 UI 图标。
7. **业务状态优先**：可预约、已预约、已满、候补、无权益、时间冲突、退款中等状态必须有明确视觉表达。
8. **P3 后置**：数字课程在 P3 才进入完整运营链路，当前用户端不作为核心导航卖点。
