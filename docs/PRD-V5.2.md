# Yoga 单店经营与会员增长系统 PRD V5.2

> 更新时间：2026-08-19  
> 产品阶段：单店 MVP → 单店增长版  
> 用户端：uni-app（微信小程序）  
> 管理端：Kotlin Multiplatform / Compose Multiplatform（仅移动端）  
> 后端：Spring Boot  
> 核心原则：先做一家店的经营闭环，不做 SaaS、多门店、Web 管理后台。

---

## 0. 文档目标

本 PRD 不只描述“有哪些页面”，而是明确：

1. 用户为什么使用产品；
2. 门店每天如何经营；
3. 每个收入产品如何销售；
4. 运营动作如何被系统触发；
5. 用户如何从低客单升级到高客单；
6. 哪些功能属于 P0/P1/P2；
7. uni-app、KMP、Spring Boot 各自负责什么。

# 1. 产品定位

## 1.1 产品定义

Yoga 是一套面向单店瑜伽馆的**经营与会员增长系统**，不是单纯的约课工具，也不是单纯的商城。

核心价值：

> 用数字化手段帮助瑜伽馆完成“获客 → 体验 → 转化 → 活跃 → 升级 → 复购 → 裂变”的会员生命周期经营，同时通过私教、小班、数字课程、商品等增加会员 LTV。

## 1.2 核心经营飞轮

```text
内容/活动/分享获客
        ↓
      体验课
        ↓
    体验 CRM 跟进
        ↓
      会员成交
        ↓
  团课 / 小班 / 私教
        ↓
   训练与会员活跃
        ↓
体态评估 / 训练计划
        ↓
数字课程 / 直播 / 训练营
        ↓
瑜伽商品 / 套餐
        ↓
   续费 / VIP 升级
        ↓
      转介绍
        ↓
       新客
```

## 1.3 核心经营指标

| 指标 | 目标 |
|---|---|
| 新客数 | 持续增长 |
| 体验到店率 | 提升 |
| 体验转会员率 | 提升 |
| 首购客单价 | 提升 |
| 会员月活跃率 | 提升 |
| 课程上座率 | 提升 |
| 私教转化率 | 提升 |
| 商品购买率 | 提升 |
| 数字课程购买率 | 提升 |
| 续费率 | 提升 |
| ARPU | 提升 |
| LTV | 提升 |
| 退款率 | 控制 |

# 2. 产品边界

## 2.1 当前必须做

- 单店会员管理
- 课程与排课
- 预约、取消、候补、签到
- 体验课 CRM
- 会员运营任务
- 团课 / 精品小班 / 私教
- 体态评估
- 会员卡与套餐
- 商品商城
- 数字课程
- 训练计划
- 直播/回放
- 训练营基础能力
- 积分与会员等级
- 订单、支付、退款基础流程
- 经营数据

## 2.2 当前明确不做

- SaaS 多租户
- 多门店
- 加盟体系
- Web 管理后台
- 开放平台
- 外部教练 marketplace
- 复杂 ERP
- 完整财务会计系统
- 大规模供应链
- 自动化 AI 教练
- 医疗诊断

## 2.3 产品原则

### 原则 A：运营优先

每一个重要数据都必须能产生一个行动。

错误：

> “14 天未训练会员 38 人。”

正确：

> “38 人待召回 → 查看名单 → 推荐线上跟练/优惠 → 分配负责人 → 完成任务。”

### 原则 B：收入产品必须可组合

课程、私教、小班、数字课程、商品不能各自孤立。

### 原则 C：先验证再重投入

数字内容先 MVP，自有商品先少 SKU，爆款再专业化。

# 5. 用户端 PRD

## 5.1 首页

### 目标

让用户打开小程序后 5 秒内知道：

- 我今天有什么课；
- 我正在进行什么训练；
- 我有哪些权益；
- 系统推荐我做什么。

### 核心模块

1. 会员状态
2. 今日课程
3. 今日训练
4. 训练连续天数
5. 直播预告
6. 活动
7. 个性化课程
8. 商品推荐
9. 到期提醒
10. 积分/权益

### 推荐规则

```text
新用户 → 体验课
新会员 → 新手训练
14天未到店 → 线上跟练
连续训练 ≥ 4周 → 小班/私教
购买训练计划 → 关联商品
即将到期 → 续费套餐
高价值会员 → VIP/私教/工作坊
```

# 12. 数字课程与训练体系

## 12.1 产品定义

数字内容不是“视频文件售卖”，而是：

> **内容 + 训练计划 + 打卡 + 数据 + 运营 + 商品推荐。**

## 12.2 四层产品

### 单节课

¥9.9-29.9。

### 7/21/30 天训练计划

¥39-299。

### 直播

每周 2-3 场，直播结束后沉淀回放。

### 训练营

¥299-599，包含录播、直播、打卡、答疑和结营报告。

## 12.3 内容生产

第一阶段：自有教练 + 手机拍摄。  
第二阶段：验证爆款后专业重制。  
第三阶段：外部教练合作，当前不做开放平台。

## 12.4 训练计划

```text
购买
 ↓
生成计划
 ↓
每日任务
 ↓
训练
 ↓
打卡
 ↓
连续训练
 ↓
阶段报告
 ↓
下一阶段推荐
```

## 12.5 数字与线下联动

```text
会员今天没来馆
→ 推荐20分钟跟练

连续训练4周
→ 推荐小班/私教

完成柔韧计划
```

# 21. MVP 验收标准

## 经营闭环

- 新用户可购买体验课
- 体验课可预约/签到
- 体验完成自动生成跟进任务
- 可成交会员卡
- 会员可预约课程
- 店长能看到今日经营
- 系统能发现沉默会员
- 店长能执行召回

## 客单价闭环

- 会员可以购买私教
- 会员可以购买小班
- 会员可以购买商品
- 课程可关联商品
- 商品可关联训练计划
- 套餐可以组合多种权益

## 数字闭环

- 用户可购买录播/训练计划
- 用户可每日训练
- 用户可打卡
- 系统记录完成率
- 直播可预约
- 直播结束有回放

# 22. 产品成功标准

第一阶段不是追求功能数量，而是验证三个问题：

### Q1：能不能让一家店更好地管理会员？

### Q2：能不能让会员平均消费更多？

### Q3：能不能让会员更久地留在店里？

如果三者都成立，再考虑扩大产品边界。
