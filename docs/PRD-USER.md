# 1. 产品概述

## 1.1 产品定义

Yoga 用户端不是简单的“约课工具”，而是会员从第一次接触瑜伽馆开始，到体验、购买课程、持续训练、购买商品、参加数字训练、续费和推荐好友的完整消费入口。

核心目标：

1. 让用户容易找到合适的课程；
2. 让预约、取消、签到简单可靠；
3. 让用户持续训练，而不是买完会员后沉默；
4. 根据用户的训练和消费行为推荐更合适的服务；
5. 通过数字课程和商品增加消费场景；
6. 让会员最终形成长期消费关系。

## 1.2 用户价值

用户打开小程序应该能够快速回答四个问题：

- 今天练什么？
- 我还有什么权益？
- 我应该继续练什么？
- 有什么适合我的课程、训练计划或商品？

# 2. 用户角色与核心场景

## 2.1 游客

可以：

- 查看瑜伽馆介绍；
- 查看课程；
- 查看教练；
- 查看活动；
- 查看商品；
- 领取/购买体验课。

不能：

- 使用会员专属课程；
- 使用会员卡；
- 预约需要会员资格的课程。

## 2.2 体验用户

典型路径：

```text
看到活动/分享
→ 购买体验课
→ 预约时间
→ 到店
→ 签到
→ 上课
→ 体验反馈
→ 推荐会员方案
```

## 2.3 普通会员

典型路径：

```text
购买会员
→ 预约课程
→ 到店签到
→ 训练
→ 查看训练记录
→ 继续预约
→ 续费
```

## 2.4 高价值会员

除基础能力外，还可能购买：

- 私教；
- 精品小班；
- 体态评估；
- 训练计划；
- 数字课程；
- 工作坊；
- 商品；
- VIP 套餐。

# 4. 登录与注册

## 4.1 登录

首次进入：

1. 展示品牌启动页；
2. 用户点击微信授权登录；
3. 获取微信身份信息；
4. 必要时获取手机号；
5. 用户确认用户协议和隐私政策；
6. 创建会员档案；
7. 进入首页。

## 4.2 会员档案

保存：

- 微信用户标识；
- 昵称；
- 头像；
- 手机号；
- 性别（用户主动提供时）；
- 生日（用户主动提供时）；
- 注册时间；
- 来源渠道；
- 推荐人。

## 4.3 异常

授权失败、手机号获取失败、网络异常时必须提供明确提示和重试入口。

首页不是广告页，而是“个人训练与消费入口”。

- 当前会员等级；
- 卡名称；
- 剩余次数；
- 到期日期；
- 快速续费。

### 5.2.2 今日课程

展示当天用户可预约的课程。

信息：

- 时间；
- 课程；
- 教练；
- 剩余名额；
- 教室；
- 预约状态。

如果用户存在训练计划，优先展示今天应该完成的任务。

# 10. 数字训练

## 10.1 产品原则

数字课程不是“买一堆视频”，而是帮助用户完成训练。

## 10.2 单节课程

例如：

- 15分钟肩颈放松；
- 20分钟晨间瑜伽；
- 30分钟睡前拉伸。

## 10.3 训练计划

例如：

### 7天肩颈训练

包含：

- 7个训练任务；
- 每日提醒；
- 完成记录；
- 连续打卡；
- 结营总结。

### 21天柔韧训练

包含：

- 21个训练任务；
- 分阶段难度；
- 每周测试；
- 训练记录。

## 10.4 训练任务状态

```text
未开始
 ↓
进行中
 ↓
已完成
```

如果用户连续多天未完成，首页提示恢复训练。

## 10.5 训练完成

完成训练后：

- 增加训练次数；
- 增加积分；
- 更新连续训练天数；
- 更新计划进度；
- 推荐下一次训练；
- 根据计划推荐相关商品。

# 18. 核心业务规则

## 18.1 预约冲突

同一用户在时间重叠的课程中不能重复预约。

## 18.2 取消

门店可设置最晚取消时间。

超过时间取消：

- 可能扣课；
- 可能记爽约；
- 规则必须在预约前明确展示。

## 18.3 爽约

用户未取消且未签到，系统记录爽约。

连续爽约达到阈值后，可触发运营提醒。

## 18.4 会员到期

到期前根据门店配置发送提醒，并推荐符合用户消费历史的续费产品。

# 19. 用户状态与异常处理

所有关键操作都要有明确结果：

| 场景 | 用户看到的结果 |
|---|---|
| 预约成功 | 成功页 + 我的课程 |
| 课程满员 | 候补入口 |
| 会员无资格 | 说明原因 + 可购买产品 |
| 支付失败 | 重新支付 |
| 订单超时 | 自动取消 |
| 取消成功 | 更新课程状态 |
| 签到成功 | 展示训练/积分结果 |
| 视频无法播放 | 重试 + 客服入口 |
| 商品缺货 | 不允许下单并提示 |

# 22. 用户端验收原则

一个功能只有同时满足以下条件才算完成：

1. 用户知道为什么使用；
2. 页面有明确入口；
3. 操作有成功/失败反馈；
4. 数据状态可追踪；
5. 会员权益正确扣减；
6. 需要运营跟进时能触发管理端任务；
7. 重要行为能够进入经营数据。
