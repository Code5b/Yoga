# 1. 商业模式总览

Yoga 单店收入不是单一课程收入，而是由五层组成：

```text
第一层：基础现金流
团课 / 会员卡 / 体验课

第二层：高客单
私教 / 精品小班 / 体态评估 / 工作坊

第三层：数字增量
录播 / 训练计划 / 直播 / 训练营

第四层：商品增量
瑜伽垫 / 服饰 / 辅助用品 / 生活方式产品

第五层：高价值业务
VIP / Retreat / 企业瑜伽 / 自有品牌
```

商业飞轮：

```text
获客
 ↓
体验
 ↓
会员
 ↓
活跃
 ↓
需求识别
 ↓
高客单升级
 ↓
数字延伸
 ↓
商品连带
 ↓
续费
 ↓
转介绍
```


# 4. 客单价提升的五种方法

通过套餐：

```text

```

```text
团课 → 小班 → 私教 → VIP
```

```text
线下课 → 线上训练 → 工作坊 → 商品 → 复训
```

## 4.4 延长生命周期

```text
新客 → 新会员 → 活跃 → 高价值 → VIP → 续费
```

## 4.5 带来新客户

```text
会员 → 邀请 → 新客 → 体验
```

# 6. 核心产品的经济角色

## 6.1 体验课

不是主要利润产品，而是获客入口。

目标：

- 降低首次消费门槛
- 识别需求
- 进入 CRM
- 转正式会员

## 6.2 会员卡

承担稳定现金流和长期关系。

建议：

- 次卡
- 月卡
- 季卡
- 年卡

## 6.3 私教

承担高客单和高毛利。

## 6.4 小班

承担“比团课贵、比私教便宜”的中间价格带。

## 6.5 体态评估

承担“低价专业入口 → 高价服务”的转换。

## 6.6 数字内容

三个作用：

1. 增量收入；
2. 线下缺席时保持活跃；
3. 引导商品和线下升级。

## 6.7 商品

不是独立电商，而是训练行为的连带消费。

# 8. 数字课程商业模式

## 8.1 产品结构

¥9.9-29.9，用于低门槛试用。

### 7/21/30 天计划

¥39-299，核心数字产品。

每周 2-3 场，直播后沉淀回放。

### 训练营

¥299-599，加入陪伴、答疑、打卡、直播。

## 8.2 为什么不一开始大量拍视频

数字内容存在制作成本，因此采用：

```text
MVP 内容
 ↓
小规模销售
 ↓
观察完成率/购买率/复购率
 ↓
爆款课程专业重制
```

## 8.3 内容生产成本控制

第一阶段：手机 + 自有教练。  
第二阶段：爆款课程专业拍摄。  
第三阶段：外部教练合作。

## 8.4 直播价值

# 10. 会员 LTV 经营

会员 LTV 不只计算会员卡收入。

```text
LTV
=
课程贡献
+
私教贡献
+
小班贡献
+
数字内容贡献
+
商品贡献
+
活动贡献
```

因此系统必须建立统一的会员收入档案。

每个会员至少记录：

```text
首购金额
课程累计
私教累计
小班累计
商品累计
数字内容累计
活动累计
退款累计
会员生命周期
```

# 11. 单店单位经济模型

## 11.1 ARPU

```text
ARPU = 期间会员收入 / 期间付费会员数
```

必须拆分：

- 课程 ARPU
- 私教 ARPU
- 商品 ARPU
- 数字 ARPU
- 活动 ARPU

## 11.2 LTV

```text
LTV ≈ 月均贡献毛利 × 平均生命周期
```

## 11.3 CAC

```text
CAC = 获客投入 / 新增付费会员
```

## 11.4 LTV/CAC

用于判断获客是否值得扩大。

## 11.5 经营看板

老板每月必须回答：

1. 新增了多少会员？
2. 体验转化是多少？
3. 会员平均消费多少？
4. 哪个产品最赚钱？
5. 哪个课程最受欢迎？
6. 哪些会员可能流失？
7. 商品连带率是多少？
8. 数字内容是否带来增量？
9. 私教是否在增长？
10. 现金流是否健康？

# 12. 运营驱动收入

商业模式必须变成规则：

| 用户状态 | 触发 | 推荐 |
|---|---|---|
| 新注册 | 未购买 | 体验课 |
| 体验完成 | 未成交 | 会员套餐 |
| 新会员 | 训练不足 | 新手计划 |
| 高频会员 | ≥3次/周 | 小班/私教 |
| 目标明确 | 体态/肩颈等 | 评估/专项计划 |
| 14天未训练 | 沉默 | 线上跟练 |
| 7天到期 | 到期风险 | 续费套餐 |
| 完成训练计划 | 已完成 | 下一阶段 |
| 购买训练计划 | 有装备需求 | 商品套餐 |
| 高价值 | 高 LTV | VIP/Retreat |

# 15. 商业模式成功标准

第一阶段不是追求 GMV 最大化，而是验证：

```text
体验转化 ↑
会员活跃 ↑
ARPU ↑
商品连带 ↑
数字内容复购 ↑
续费率 ↑
LTV ↑
```

如果一个功能不能改善上述指标，也不能形成明显的经营效率提升，应降低优先级。
