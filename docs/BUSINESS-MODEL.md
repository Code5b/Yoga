# Yoga 单店商业模式 V7.0

> 本文不是技术说明，而是一份可以给瑜伽馆老板、合作伙伴、投资人阅读的商业说明书。核心问题只有三个：**为什么用户愿意持续付钱、门店为什么能够赚钱、这个模型为什么可以逐步放大。**

---

# 1. 一句话理解项目

Yoga 要帮助一家单店瑜伽馆从“卖团课”升级为：

> **以会员长期训练为核心，同时经营团课、精品小班、私教、数字训练、瑜伽商品和活动的综合瑜伽消费业务。**

因此收入不再只有一条：

```text
传统瑜伽馆
= 会员卡/团课
```

而是：

```text
基础收入：会员卡/团课
+
高客单：私教/小班/评估/工作坊
+
数字收入：录播/训练计划/直播/训练营
+
商品收入：瑜伽装备/服饰/生活方式
+
复购收入：续费/升级/套餐
+
增量收入：推荐/企业瑜伽/Retreat（后期）
```

---

# 2. 为什么只卖瑜伽课容易遇到瓶颈

传统门店主要依赖“场地 × 时间 × 教练”。

一节课有固定容量：例如最多20人。

一天可排课时间有限，教练工作时间有限，场地面积也有限。

所以收入天然受到：

```text
场地容量
×
可营业时间
×
课程上座率
×
会员支付能力
```

限制。

如果只卖团课，门店提高收入通常只能：

1. 涨价；
2. 增加会员数量；
3. 增加排课；
4. 提高上座率。

前三项都会很快碰到物理瓶颈。

Yoga 的思路是：

> **在不无限增加场地和教练工时的情况下，提高每一个会员的年消费价值。**

---

# 3. 用户消费阶梯

用户不是一上来就购买最高价产品。

设计消费阶梯：

```text
免费内容
 ↓
体验课
 ↓
单次课
 ↓
次卡/月卡
 ↓
季卡/年卡
 ↓
精品小班
 ↓
体态评估
 ↓
私教
 ↓
训练计划
 ↓
数字课程
 ↓
瑜伽商品
 ↓
VIP/工作坊
```

每一级解决不同需求。

商业目标不是强迫用户升级，而是：

> **当用户产生新需求时，门店已经有产品承接。**

---

# 4. 六条收入线

## 4.1 会员/团课

这是基础现金流。

产品：

- 单次体验
- 次卡
- 月卡
- 季卡
- 年卡

特点：收入稳定、复购强，但容量受场地限制。

## 4.2 私教

特点：客单价高、依赖教练能力、容量有限。

适合：

- 有明确目标的人
- 新手需要指导的人
- 希望快速进阶的人
- 体态问题明显但不涉及医疗诊断的人

## 4.3 精品小班

例如：

- 肩颈专项
- 柔韧专项
- 后弯
- 倒立
- 核心

相比普通团课人数少、主题更明确，因此可以获得更高客单。

## 4.4 数字训练

数字产品解决：

> “我喜欢瑜伽，但是没有时间每天到店。”

产品：

- 15-30分钟短课
- 7天训练
- 21天训练
- 30天训练
- 直播
- 回放
- 训练营

优势：一次生产可以服务大量用户，边际成本低于到店课程。

## 4.5 商品

商品不是独立电商，而是围绕训练需求销售：

```text
柔韧训练
→ 瑜伽砖/瑜伽带

居家训练
→ 瑜伽垫

高温瑜伽
→ 毛巾/水杯

日常训练
→ 瑜伽服
```

## 4.6 活动

工作坊、主题课、训练营、Retreat 等用于提高会员参与和额外消费。

---

# 5. 为什么商品可以提高客单价

假设会员原本每月只消费课程。

如果通过训练场景自然产生商品需求：

```text
月课程消费 ¥500
+
平均商品消费 ¥100
=
¥600/月
```

商品不是要求每个人都买，而是让有需求的人有购买入口。

关键指标：

> **商品联购率。**

不是单纯追求商品销售额。

---

# 6. 数字课程为什么值得做

传统到店课程：

```text
1个教练
×
1个时间段
×
1个教室容量
```

数字课程：

```text
一次生产
→ 无限次播放
```

当然也存在制作成本和内容营销成本，但边际服务成本低。

数字产品最重要的意义不是马上赚很多钱，而是：

1. 延长用户训练时间；
2. 召回没有时间到店的人；
3. 增加会员使用场景；
4. 为低价用户提供入口；
5. 为商品提供训练场景；
6. 提高会员生命周期价值。

---

# 7. 数字课程生产模型

第一阶段不需要专业摄影棚。

使用：

- 手机
- 三脚架
- 麦克风
- 基础灯光

先验证需求。

流程：

```text
会员需求
→ 选题
→ 教练脚本
→ 手机拍摄
→ 剪辑
→ 审核
→ 上架
→ 数据验证
```

只有验证销售和完成率后，才投入更高制作成本。

---

# 8. 训练计划比视频更重要

如果只卖：

> “100个瑜伽视频 ¥99”

用户容易买完不看。

更好的产品：

> “21天肩颈训练计划 ¥99”

里面包含：

```text
Day 1
Day 2
...
Day 21

每日提醒
打卡
连续训练
阶段反馈
结营
```

因此用户买的是：

> **一个训练结果，而不是一堆视频。**

---

# 9. 直播商业模式

直播有三种用途：

### 免费直播

目的：活跃会员、增强关系。

### 低价直播

例如主题课、专项课。

目的：产生小额数字收入。

### 训练营直播

直播只是训练营的一部分。

目的：提高训练完成率和产品价值。

直播不应该完全替代到店课，而应该成为到店之外的训练场景。

---

# 10. 客单价提升模型

客单价提升不是简单涨价。

应该是：

```text
基础消费
+
适合用户的新需求
+
相关商品
+
数字训练
+
高级服务
```

例如：

```text
用户 A

月卡 ¥499
+
21天柔韧训练 ¥99
+
瑜伽砖 ¥59
+
工作坊 ¥129

月度/阶段消费价值 = ¥786
```

注意：以上只是模型示例，不是承诺价格。

---

# 11. ARPU

ARPU = 某周期总收入 / 该周期活跃付费用户数。

例如：

```text
月收入 ¥100,000
活跃付费会员 200

ARPU = ¥500
```

提高 ARPU 有四条路：

1. 提高会员续费；
2. 增加私教/小班；
3. 增加数字消费；
4. 增加商品联购。

---

# 12. LTV

LTV 可以粗略理解为：

> 一个用户从进入门店到离开，累计贡献的毛利价值。

简化模型：

```text
LTV
≈
平均月消费
×
平均有效消费月数
×
毛利率
```

例如假设：

```text
月消费 ¥600
平均消费 12个月
毛利率 60%
```

粗略毛利 LTV：

```text
600 × 12 × 60% = ¥4,320
```

真实模型还要考虑获客成本、退款、不同产品毛利等。

---

# 13. CAC

CAC = 获得一个有效付费客户的营销成本。

例如：

```text
一个月营销费用 ¥20,000
新增有效付费客户 50

CAC = ¥400
```

健康模型要求：

> LTV 必须明显高于 CAC。

不能靠低价体验不断烧钱，而没有长期消费。

---

# 14. 单店经济模型

门店总收入：

```text
会员/团课
+
私教
+
小班
+
数字
+
商品
+
活动
=
总收入
```

门店成本：

```text
房租
+
教练成本
+
前台/店长工资
+
水电物业
+
营销
+
商品采购
+
支付手续费
+
软件及内容成本
+
其他
=
总成本
```

经营利润：

```text
总收入 - 总成本 = 门店经营利润
```

---

# 15. 盈亏平衡

假设门店每月固定成本为 F，每个会员贡献的月毛利为 M：

```text
盈亏平衡会员数 ≈ F / M
```

例如只是为了理解模型：

```text
固定成本 ¥100,000/月

每个活跃会员平均贡献毛利 ¥500/月

盈亏平衡 ≈ 200个会员
```

这不是项目财务预测，而是帮助投资人理解门店经济模型。

真正财务模型应由实际租金、教练工资、会员数量、价格、商品成本等数据重新测算。

---

# 16. 会员生命周期收入模型

假设一个用户：

```text
体验课 ¥49
→ 月卡
→ 年卡
→ 私教
→ 数字训练
→ 商品
→ 工作坊
→ 续费
```

传统门店可能只获得会员卡收入。

Yoga 希望把后续需求全部承接。

因此核心指标不是：

> “卖了多少张年卡。”

而是：

> **一个用户一年到底贡献了多少收入和毛利。**

---

# 17. 运营如何产生收入

运营不是“发优惠券”。

运营的核心是减少收入损失。

## 场景 A：会员14天没训练

如果不处理：可能流失。

处理：

```text
系统发现
→ 召回
→ 线上训练
→ 恢复训练
→ 延长生命周期
```

## 场景 B：会员7天到期

如果不处理：可能自然流失。

处理：

```text
到期提醒
→ 复盘训练
→ 推荐续费
→ 续费
```

## 场景 C：高频会员

如果不处理：继续只买团课。

处理：

```text
发现高频
→ 推荐专项小班/私教
→ 增购
```

所以：

> **运营任务直接对应收入指标。**

---

# 18. 体验课商业漏斗

```text
曝光
↓
访问
↓
注册
↓
体验购买
↓
预约
↓
到店
↓
完课
↓
正式会员
```

每一步都有损失。

因此不能只看“今天来了多少人”，必须看漏斗。

核心指标：

- 到店率
- 完课率
- 体验转化率
- 首购客单
- 首购后30天留存

---

# 19. 私教商业模型

私教的价值不是单纯高价。

它可以解决：

- 个性化需求
- 教练指导
- 训练目标
- 会员升级

模型：

```text
高活跃会员
→ 发现明确目标
→ 评估
→ 私教
→ 训练计划
→ 复购
```

关键指标：

- 体验→私教转化
- 私教客单
- 私教完成率
- 私教续购率

---

# 20. 精品小班模型

小班是团课与私教之间的产品。

特点：

```text
人数少
主题明确
价格高于普通团课
低于1对1私教
```

适合承接：

> “我想解决一个明确问题，但暂时不想买私教。”

---

# 21. 商品模型

## 第一期：精选商品

SKU少，验证需求。

建议优先：

- 瑜伽砖
- 瑜伽带
- 瑜伽垫
- 毛巾
- 水杯
- 基础服饰

## 第二期：训练套餐

```text
课程 + 装备
训练计划 + 装备
会员 + 商品
```

## 第三期：自有品牌

只有在销量稳定后才考虑。

这样可以降低库存和现金流风险。

---

# 22. 商品为什么不能变成普通电商

如果商城里有大量无关商品，会导致：

- 库存压力
- 运营复杂
- 低毛利
- 用户心智混乱

所以商品必须回答：

> **“这个商品为什么对我的瑜伽训练有帮助？”**

这也是 Yoga 与普通电商最大的区别之一。

---

# 23. 数字产品与商品的联动

例如用户购买：

> 21天柔韧训练。

系统推荐：

```text
瑜伽砖
瑜伽带
```

用户训练过程中又发现：

> 居家训练不方便。

再推荐：

> 家用瑜伽垫。

形成：

```text
内容
→ 训练
→ 产生需求
→ 商品
→ 提高训练体验
→ 提高留存
```

# 26. 为什么先做单店

现在不做 SaaS 是主动选择。

原因：

1. 先验证门店经营模型；
2. 验证用户是否愿意购买数字产品；
3. 验证商品联购；
4. 验证运营 SOP；
5. 获取真实经营数据；
6. 避免过早做复杂多租户系统。

先证明：

> **一家店能够通过系统产生更多收入和更高留存。**

再考虑复制。

# 27. 未来扩张逻辑

不是一开始就做 SaaS，而是：

```text
单店
 ↓
经营模型验证
 ↓
第二家自营/合作店
 ↓
多店标准化
 ↓
SOP标准化
 ↓
系统多租户
 ↓
SaaS
```

真正的 SaaS 应该来自已经被验证的业务模型，而不是先开发一套 SaaS 再找业务。

# 28. 核心竞争壁垒

第一阶段壁垒不是技术。

更重要的是：

### 1. 运营 SOP

知道什么情况下应该做什么。

### 2. 用户数据

知道用户为什么训练、什么时候流失、喜欢什么产品。

### 3. 产品组合

团课、小班、私教、数字、商品相互承接。

### 4. 内容资产

训练计划和数字课程不断沉淀。

### 5. 用户关系

通过长期训练形成会员关系，而不是一次性交易。

# 29. 投资人看什么

投资人通常会关心：

## 市场

目标用户是否足够大？

## 单店经济

单店是否盈利？

## LTV/CAC

用户长期价值是否覆盖获客成本？

## 增长

新店/新用户能否复制？

## 毛利

## 留存

用户是否持续训练和消费？

## 规模化

未来是否可以从单店走向多店/SaaS/品牌？

指标：单店经营利润。

# 35. 风险

## 内容风险

数字课程质量差 → 完成率低 → 先小规模验证。

## 库存风险

商品卖不动 → 现金占用 → SKU少、低库存。

## 销售风险

过度营销 → 用户反感 → 推荐必须基于真实需求。

## 教练风险

过度依赖个人教练 → 难复制 → SOP化训练服务。

## 门店风险

房租高/上座率低 → 盈亏平衡困难 → 用实际门店数据持续调整。

# 36. 最终商业逻辑

Yoga 最终要证明的不是：

> “我们做了一个瑜伽小程序。”

而是：
