# 1. 先理解 Yoga 在解决什么问题

传统瑜伽馆通常只卖课程：

```text
会员
 ↓
买月卡/次卡
 ↓
上团课
 ↓
到期
 ↓
续费或流失
```

这种模式的问题是，一个会员的收入来源比较单一。

Yoga 希望把一个会员的消费变成一条完整路径：

```text
体验课
 ↓
会员卡
 ↓
团课
 ↓
精品小班
 ↓
体态评估
 ↓
私教
 ↓
训练计划
 ↓
数字课程
 ↓
瑜伽商品
 ↓
工作坊
 ↓
VIP
 ↓
续费
 ↓
推荐好友
```

所以 Yoga 的商业目标不是单纯“多卖几节课”，而是：

> **在不强迫用户消费的前提下，为用户提供越来越适合他的产品，让一个满意会员在更长时间里产生更多合理消费。**

# 2. 五个核心赚钱方法

## 2.1 多获得新会员

例如一个月新增 50 个会员。

方法：

- 体验课；
- 老会员推荐；
- 工作坊；
- 线上内容；
- 社交分享。

## 2.2 让第一次消费更容易

例如：

> ¥39 体验课

比直接让陌生用户购买 ¥1,999 年卡更容易。

## 2.3 让会员购买更高价值产品

例如：

```text
月卡 ¥399
 ↓
精品小班 ¥999
 ↓
私教套餐 ¥2,999
```

## 2.4 让会员购买更多东西

例如：

```text
课程
+
瑜伽垫
+
瑜伽砖
+
训练计划
```

## 2.5 让会员留下更久

例如一个会员每月消费 ¥500：

- 留 3 个月 = ¥1,500；
- 留 12 个月 = ¥6,000；
- 留 24 个月 = ¥12,000。

因此续费率和会员生命周期非常重要。

# 3. 收入结构

Yoga 单店收入分为五层。

## 第一层：基础课程收入

这是门店最稳定的现金流。

包括：

- 体验课；
- 次卡；
- 月卡；
- 季卡；
- 年卡。

目标：让大量普通会员持续消费。

## 第二层：高客单服务

所谓高客单，就是一次消费金额明显高于普通团课。

包括：

- 私教；
- 精品小班；
- 体态评估；
- 工作坊。

例如：

```text
普通团课：¥50/次
小班：¥150/次
私教：¥300/次
```

不要求所有人购买私教，而是把真正需要更专业服务的人引导过去。

## 第三层：数字收入

包括：

- 单节录播课；
- 7/21/30 天训练计划；
- 直播；
- 训练营。

数字内容的最大价值有两个：

1. 用户不能到店时仍然可以训练；
2. 内容生产一次后可以重复销售。

因此数字内容既是收入产品，也是会员留存工具。

## 第四层：商品收入

包括：

- 瑜伽垫；
- 瑜伽服；
- 瑜伽砖；
- 瑜伽带；
- 防滑袜；
- 毛巾；
- 水杯；
- 运动包；
- 自有品牌。

商品不是独立商城，而是跟用户的训练场景关联。

例如：

```text
用户购买肩颈训练计划
→ 推荐瑜伽砖

用户参加高温瑜伽
→ 推荐毛巾和水杯

用户参加普拉提
→ 推荐防滑袜
```

## 第五层：长期增量

当单店经营稳定后，再考虑：

- Yoga Retreat；
- 企业瑜伽；
- 自有品牌；
- 教练培训；
- 教练内容合作。

这些不是第一阶段收入目标。

# 6. 三个最重要的经营指标

## 6.1 ARPU：平均每个会员贡献多少钱

简单理解：

> 一段时间内，平均一个付费会员花了多少钱。

例如：

```text
100个会员
一个月总消费 ¥50,000

ARPU = ¥50,000 / 100 = ¥500
```

提高 ARPU 的方法：私教、小班、商品、数字课程、工作坊、套餐升级。

## 6.2 LTV：一个会员一生能贡献多少钱

简单理解：

> 从第一次消费到最终离开，一个会员总共贡献多少钱。

简化理解：

```text
平均每月消费 ¥600
×
平均留存 12 个月
=
约 ¥7,200
```

提高 LTV：

```text
提高消费金额
+
增加消费频次
+
延长会员生命周期
```

## 6.3 CAC：获得一个新付费会员需要多少钱

例如一个月花 ¥5,000 做推广，得到 20 个新付费会员：

```text
CAC = ¥5,000 / 20 = ¥250
```

把 CAC 与 LTV 放在一起看，才能判断推广是否值得继续扩大。

# 8. 数字课程商业模式

## 8.1 为什么做

数字课程不是为了替代线下课程，而是解决：

> “会员今天没有时间到店怎么办？”

它同时承担三种价值：

1. 增加收入；
2. 保持会员训练习惯；
3. 为线下服务和商品提供新的推荐入口。

## 8.2 第一阶段怎么做

不要先拍 100 条视频。

先做：

```text
3个免费内容
+
3个低价单节课
+
2个训练计划
+
每周2场直播
```

用真实数据验证需求。

## 8.3 视频是不是必须自己拍

第一阶段建议由店内教练自己生产。设备可以非常简单：

- 手机；
- 三脚架；
- 麦克风；
- 简单灯光。

重点是动作示范、声音、讲解和训练结构，而不是电影级画质。

## 8.4 内容验证

```text
选题
→ MVP拍摄
→ 上架
→ 用户购买
→ 查看完成率
→ 查看复购
→ 爆款专业重制
```

## 8.5 产品阶梯

```text
免费
 ↓
¥9.9-29.9 单节
 ↓
¥39-99 7天计划
 ↓
¥99-199 21天计划
 ↓
¥299-999 训练营
```

# 9. 商品商业模式

## 9.1 第一阶段：少量自营

只选高关联 SKU，避免压库存：

- 瑜伽垫；
- 瑜伽砖；
- 瑜伽带；
- 毛巾；
- 防滑袜；
- 水杯。

## 9.2 第二阶段：寄售

品牌提供商品，门店销售，按约定周期结算。

优点：门店资金压力较低。

## 9.3 第三阶段：联营

品牌和门店共同承担营销，根据销售额或毛利按协议分成。

## 9.4 第四阶段：自有品牌

等某一类商品已经证明稳定销售后，再考虑自己的瑜伽垫、毛巾、水杯、服饰等。

# 10. 会员运营如何变成收入

系统不能只告诉店长“有多少会员”，必须回答：

> **今天应该找谁？为什么找？应该提供什么？什么时候再找？结果怎样？**

### 场景 A：体验完成

```text
体验完成
→ 当天感谢
→ T+1了解感受
→ T+3推荐方案
→ T+7再次跟进
```

### 场景 B：14天没训练

```text
14天未训练
→ 创建召回任务
→ 推荐20分钟线上课程
→ 用户恢复训练
```

### 场景 C：连续训练

```text
连续训练4周
→ 判断训练目标
→ 推荐小班/私教
```

### 场景 D：即将到期

```text
到期前7天
→ 发送提醒
→ 查看历史消费
→ 推荐匹配的续费套餐
```

### 场景 E：买了训练计划

```text
购买训练计划
→ 完成训练
→ 推荐相关训练装备
```

# 15. 最重要的商业原则

1. **不强卖**：推荐必须建立在用户真实行为和需求上。
2. **先服务，再销售**：先让用户获得训练体验，再推荐升级产品。
3. **卖结果，不只卖次数**：例如“8周体态改善”比单纯“8节课”更容易表达价值。
4. **商品服务于训练**：不要把瑜伽馆变成杂货店。
5. **数字课程服务于留存**：不能到店时仍然可以训练。
6. **所有动作最终回到 LTV**：长期满意、训练、复购，比一次性成交更重要。
