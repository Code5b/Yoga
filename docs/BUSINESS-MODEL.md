# Yoga 单店商业模式 V5.1

> 更新时间：2026-08-19  
> 阶段：单店验证 → 单店增长  
> 产品形态：uni-app 用户端 + KMP 移动管理端 + Spring Boot  
> 核心目标：突破“只卖瑜伽课程”的收入天花板，提高 ARPU、LTV、续费率、复购率与毛利。

---

# 1. 商业定位

Yoga 服务的不是“课程预约”本身，而是瑜伽馆老板对**会员生命周期和收入结构**的经营。

核心经营公式：

```text
收入增长
=
新客数量 × 首购转化率 × 首购客单
+
存量会员数量 × 复购率 × 客单价
+
商品/数字内容/活动等增量收入
```

核心飞轮：

```text
获客
 ↓
低门槛体验
 ↓
会员转化
 ↓
高频训练
 ↓
体态/需求识别
 ↓
小班/私教/训练计划
 ↓
数字内容
 ↓
商品
 ↓
续费/VIP
 ↓
转介绍
 ↓
获客
```

# 3. 客单价提升机制

不要把“提高客单价”理解成单纯涨价，而是建立四种增长方式。

## 3.1 一次买更多

通过套餐：

```text
团课
+
体态评估
+
训练计划
+
商品
```

## 3.2 买更高价值的服务

```text
团课 → 小班 → 私教
```

## 3.3 买得更频繁

```text
线下课程
→ 线上训练
→ 工作坊
→ 商品
→ 复训
```

## 3.4 延长生命周期

```text
新客 → 会员 → 活跃 → VIP → 续费 → 转介绍
```

# 5. 核心产品设计

## 5.1 体验课

定位：低门槛获客，不以体验课利润为核心。

建议：

- ¥39-99
- 限购一次
- 体验后自动进入 CRM
- 体验完成后触发跟进 SOP

目标指标：

- 预约率
- 到店率
- 完课率
- 体验→会员转化率

## 5.2 会员卡

建议至少包含：

- 次卡
- 月卡
- 季卡
- 年卡

不要只靠折扣区分，而是通过：

- 预约优先级
- 工作坊权益
- 数字内容
- 商品折扣
- 私教优惠

形成等级差异。

## 5.3 私教

私教是单店高客单核心。

产品结构：

```text
单节
 ↓
5节
 ↓
10节
 ↓
20节
 ↓
私教 + 体态评估 + 数字训练
```

## 5.4 精品小班

3-6 人，定位为团课与私教之间的产品。

适合：

- 体态
- 肩颈
- 腰背
- 柔韧
- 核心
- 初学者
- 进阶

## 5.5 体态评估

价格 ¥99-299。

不是孤立卖评估，而是作为高价值服务入口：

```text
评估
 ↓
报告
 ↓
训练建议
 ↓
小班/私教/数字计划
```

## 5.6 工作坊

利用周末、节假日和热门主题增加消费频次。

## 5.7 数字内容

数字内容承担三种角色：

1. 增量收入
2. 会员留存
3. 商品/线下升级入口

内容形态：

```text
单节录播
 ↓
7/21/30天训练计划
 ↓
直播
 ↓
训练营
```

## 5.8 商品

商品不做独立电商，而是：

> **围绕会员的训练行为进行连带销售。**

例如：

```text
柔韧训练
→ 瑜伽砖
→ 瑜伽带

高温瑜伽
→ 毛巾
→ 水杯

普拉提
→ 防滑袜
→ 弹力带
```

# 7. 数字课程商业实施

## 7.1 不建议第一天拍大量视频

第一阶段采用 MVP：

```text
3个免费内容
+
3个低价单节课
+
2个训练计划
+
每周2场直播
```

先验证：

- 开始率
- 完成率
- 打卡率
- 购买率
- 复购率
- 对线下课程的促进
- 商品连带购买

## 7.2 内容生产

第一阶段：自有教练手机拍摄。  
第二阶段：爆款课程专业重制。  
第三阶段：外部教练合作。

## 7.3 直播

每周固定 2-3 场，不要求每天直播。

直播回放沉淀为数字资产。

## 7.4 训练营

训练营卖的是“陪伴与结果”：

- 录播
- 直播
- 打卡
- 答疑
- 动作纠正
- 结营报告

# 8. 商品商业模式

## 8.1 第一阶段：少量自营

只选择高相关 SKU，控制库存。

## 8.2 第二阶段：寄售

品牌供货，门店销售，按约定结算。

## 8.3 第三阶段：联营

品牌与门店共同承担营销，按销售额/毛利分成。

## 8.4 第四阶段：自有品牌

优先考虑：

- 瑜伽垫
- 毛巾
- 水杯
- 服饰
- 收纳包

自有品牌必须在有稳定销量后推进。

# 9. 运营自动化带来的收入提升

系统每天寻找收入机会。

| 用户状态 | 系统判断 | 推荐动作 |
|---|---|---|
| 新注册 | 未购买 | 体验课 |
| 体验完成 | 未成交 | 会员套餐 |
| 新会员 | 低频 | 新手训练 |
| 高频训练 | ≥3次/周 | 小班/私教 |
| 肩颈偏好 | 高频相关课程 | 肩颈计划 |
| 14天未训练 | 沉默 | 线上跟练/召回 |
| 7天内到期 | 到期风险 | 续费套餐 |
| 完成训练计划 | 有训练习惯 | 下一阶段计划 |
| 购买训练计划 | 有装备需求 | 商品套餐 |
| 高价值 | 高 LTV | VIP/私教/Retreat |

# 11. 单店单位经济模型

## 11.1 核心指标

### ARPU

```text
期间会员收入 / 期间付费会员数
```

建议同时拆分：

```text
课程 ARPU
+
私教 ARPU
+
数字内容 ARPU
+
商品 ARPU
+
活动 ARPU
```

### LTV

简化模型：

```text
LTV ≈ 月均贡献毛利 × 平均会员生命周期（月）
```

更完整：

```text
LTV
=
课程贡献毛利
+
私教贡献毛利
+
商品贡献毛利
+
数字内容贡献毛利
+
活动贡献毛利
```

### CAC

```text
获客成本 / 新增付费会员
```

### LTV/CAC

```text
LTV / CAC
```

用于判断获客是否值得扩大。

## 11.2 客单结构

每个会员都记录：

```text
首购金额
+
课程累计消费
+
私教累计消费
+
商品累计消费
+
数字内容累计消费
+
活动累计消费
=
会员累计收入
```

# 14. 商业原则

1. 先做单店，不提前设计 SaaS 多租户复杂度。
2. 先做高频经营闭环，再做低频高级业务。
3. 先验证商品需求，再扩 SKU。
4. 先验证数字课程，再投入专业制作。
5. 商品必须和服务、课程、训练行为绑定。
6. 数字课程必须和打卡、提醒、训练计划结合。
7. 高客单产品必须有低门槛入口和升级路径。
8. 运营动作必须可追踪到负责人、结果和收入。
9. KMP 是唯一管理后台，不做 Web 管理后台。
10. 技术实现只使用 uni-app + Kotlin/KMP + Spring Boot 作为产品核心技术栈。
