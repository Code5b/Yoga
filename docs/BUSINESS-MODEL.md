# Yoga 单店商业模式 V5.0

> 更新时间：2026-08-19  
> 阶段：单店验证  
> 核心目标：突破“只卖瑜伽课程”的收入天花板，提高 ARPU、LTV、续费率与复购率。

## 1. 商业定位

Yoga 的核心不是做一个课程预约工具，而是帮助瑜伽馆经营会员生命周期：

> 获客 → 体验 → 转化 → 活跃 → 升级 → 复购 → 续费 → 转介绍

收入不再只有课程，而是形成：

```text
课程收入
+
高客单价服务
+
商品收入
+
数字内容收入
+
活动收入
+
B2B收入
```

## 4. 六条核心增收路线

### 4.1 私教

建议产品：

- 单节
- 5 节
- 10 节
- 20 节
- 私教 + 训练计划

定位：最高优先级的 B2C 高客单服务。

### 4.2 精品小班

建议 3-6 人：

- 体态改善
- 肩颈改善
- 腰背改善
- 柔韧性
- 核心训练
- 初学者
- 进阶瑜伽

定位：团课与私教之间的利润产品。

### 4.3 训练计划

例如：

- 7 天肩颈训练：¥39-99
- 21 天柔韧训练：¥99-199
- 30 天瑜伽入门：¥129-299

核心卖点不是视频数量，而是：

> 用户购买“训练结果”。

### 4.4 商品

优先品类：

- 瑜伽垫
- 瑜伽服
- 瑜伽砖/带/球
- 防滑袜
- 毛巾
- 水杯
- 运动包

长期：

- 自有品牌
- 品牌寄售
- 品牌联营

早期避免大量库存。

### 4.5 工作坊与 Retreat

工作坊：¥199-999。  
Retreat：¥1,999-9,999+。

适合：

- 肩颈
- 倒立
- 后弯
- 呼吸
- 冥想
- 户外瑜伽
- 瑜伽旅行

### 4.6 企业瑜伽

提供：

- 企业瑜伽
- 午休瑜伽
- 肩颈健康
- 企业减压
- 团建

建议按次、人数、月度或年度收费，形成 B2B 收入线。

## 5. 数字内容商业模式

### 5.1 为什么做数字内容

数字内容不是替代线下课程，而是解决：

1. 会员没时间到店
2. 降低流失
3. 增加训练频率
4. 形成低边际成本收入
5. 为商品提供推荐入口
6. 为训练营提供内容基础

### 5.2 内容结构

```text
单节录播
 ↓
训练计划
 ↓
直播跟练
 ↓
训练营
```

### 5.3 生产策略

第一阶段：

- 自有教练
- 手机
- 三脚架
- 麦克风

第二阶段：

- 验证爆款后专业拍摄

第三阶段：

- 外部教练合作
- 平台抽成

不要在需求验证前大量投入拍摄成本。

### 5.4 直播策略

每周 2-3 场，每场 45-60 分钟。

直播结束沉淀回放，形成长期内容资产。

### 5.5 训练营

例如：21 天体态训练营 ¥299-599：

- 21 节录播
- 每周 2 次直播
- 每日打卡
- 教练答疑
- 动作纠正
- 阶段测试
- 结营报告

## 6. 商品与服务联动

商品不作为孤立商城，而是围绕用户行为推荐。

```text
课程
 ↓
训练需求
 ↓
装备推荐
 ↓
商品购买
```

示例：

- 普拉提 → 防滑袜/弹力带
- 柔韧训练 → 瑜伽砖/瑜伽带
- 高温瑜伽 → 毛巾/水杯
- 户外瑜伽 → 运动包/帽子

## 7. 套餐策略

### 新手成长包

体验课 + 体态评估 + 3 节团课 + 瑜伽垫 + 线上训练计划。

### 体态改善计划

体态评估 + 8 节团课 + 4 节私教 + 线上训练计划 + 辅助用品。

### VIP 年卡

全年团课 + 私教额度 + 体态评估 + 工作坊 + 商品折扣 + 数字训练内容。

核心原则：

> 不只是多卖一个商品，而是把多个产品组合成一个“结果型产品”。

## 9. 运营自动化

系统每天识别经营机会：

### 会员到期

> 7 天内到期 → 推荐续费套餐。

### 会员沉默

> 14 天未训练 → 推荐线上跟练/召回活动。

### 高频会员

> 每周训练 ≥ 3 次 → 推荐精品小班/私教。

### 训练计划用户

> 完成训练计划 → 推荐下一阶段计划和装备。

### 高价值会员

> 消费达到阈值 → 推荐 VIP、私教、Retreat。

## 10. 核心经营指标

### ARPU

```text
会员收入 / 付费会员数
```

### LTV

```text
单会员生命周期累计收入
```

### 续费率

```text
续费会员 / 到期会员
```

### 客单价

```text
GMV / 订单数
```

### 商品购买率

```text
购买商品会员 / 活跃会员
```

### 数字内容购买率

```text
购买数字内容会员 / 活跃会员
```

### 私教转化率

```text
购买私教会员 / 活跃会员
```

## 12. 商业原则

1. **先卖服务，再延伸商品。**
2. **先验证需求，再投入内容制作。**
3. **数字内容卖结果，不卖视频数量。**
4. **商品必须和课程/训练行为关联。**
5. **高客单产品必须有清晰升级路径。**
6. **运营系统必须主动推动会员升级，而不是只展示数据。**
7. **单店阶段不做 SaaS，多门店和平台化放到后续阶段。**
